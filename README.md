&#x20;  # Akıllı Evcil Hayvan Asistanı



&#x20;  Nesne Tabanlı Programlama dersi dönem projesi. Evcil hayvanların sağlık, aşı,

&#x20;  ilaç ve kilo takibini yapan, yapay zeka destekli bir masaüstü uygulaması.



&#x20;  ## Kullanılan Teknolojiler

&#x20;  - C# / Windows Forms (.NET 10), Visual Studio 2026

&#x20;  - DevExpress WinForms bileşenleri

&#x20;  - SQL Server LocalDB + Entity Framework Core

&#x20;  - Google Gemini API (yapay zeka asistanı)



&#x20;  ## Proje Yapısı

&#x20;  - \*\*PetAsistan.Entities\*\*: Varlık (entity) sınıfları

&#x20;  - \*\*PetAsistan.DataAccess\*\*: Veritabanı erişimi (EF Core)

&#x20;  - \*\*PetAsistan.Business\*\*: İş kuralları ve doğrulama

&#x20;  - \*\*PetAsistan.AI\*\*: Yapay zeka servisleri

&#x20;  - \*\*PetAsistan.WinUI\*\*: DevExpress arayüzü
